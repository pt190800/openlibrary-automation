רקע

מה זה E2E Testing?

Unit Test בודק פונקציה אחת בבידוד. מהיר — אבל לא רואה את התמונה הגדולה. משתמש ב-mock במקום דפדפן.
E2E Test מפעיל דפדפן אמיתי, מנווט כמו משתמש. אין mock. אם האתר משתנה — הטסט מתריע.

Design Patterns

תבניות עיצוב בפרויקט

Page Object Model כל דף באתר = class נפרד עם כל ה-selectors שלו.
הטסט לא יודע איך הדף בנוי — רק קורא למתודה.
→ pages/search_page.py · book_page.py
Facade LibraryFlows מסתיר את כל ה-Page Objects מאחורי API פשוט.
הטסט קורא flows.search() — לא יודע מה עובד מתחת.
→ utils/flows.py
Template Method BasePage מגדיר skeleton: navigate, click, screenshot.
כל subclass מוסיף את הלוגיקה הספציפית שלו.
→ pages/base_page.py (ירושה לכולם)
Retry / Exponential Backoff כישלון → המתנה → ניסיון חוזר עם זמן הכפלה.
מגן מפני חסימות זמניות בלי להפיל את כל הטסט.
→ base_page.navigate() — 4 ניסיונות: 5→10→20→40s

מנגנונים

Exponential Backoff + Delta Assertion

Exponential Backoff — vs HTTP 429
_BACKOFF_BASE = 5 # 5→10→20→40s for attempt in range(4): resp = await page.goto(url) if resp.status != 429: return # ✓ wait = _BACKOFF_BASE * (2**attempt) wait += random.uniform(-2, 2) # jitter await asyncio.sleep(wait)
Jitter — רעש ±2s. מונע מריצות מקבילות לפגוע בשרת בדיוק אותו זמן.
+ תנועת עכבר אנושית · + delays אקראיים · + הסרת webdriver flag
Delta Assertion — עמיד לריצות חוזרות
# ❌ ריצה שנייה שוברת: assert count == 5 # → 10 בריצה שנייה
# ✓ מודד שינוי, לא ערך מוחלט before = await flows.get_reading_list_count() added = await flows.add_books_to_reading_list(urls) after = await flows.get_reading_list_count() assert after - before == added
למה לא לנקות? מחיקה = פעולה נוספת שיכולה לגרום ל-429. Delta פותרת בלי סיכון.

מסקנות

מה לוקחים מהפרויקט

כישלון שקט None → exception, לא המשך selector שמחזיר None בשקט גרוע יותר מקריסה. הטסט "יעבור" בלי לבדוק כלום.
Selectors טקסט יציב יותר מ-class :has-text() עמיד לשינויי CSS. Class names משתנים ברדיזיין — טקסט פחות. DevTools לפני קוד.
POM הפרדת אחריות — השקעה שחוזרת כשהאתר שינה כפתורים — תיקנו 3 שורות ב-Page Object. הטסטים לא ידעו שמשהו השתנה.
Real-world אל תניח — תבדוק "בטח אין ספרים מ-1800" — יש, מ-1484. הריצה הראשונה תשבור הנחות — בדיוק בשביל זה עושים E2E.

רקע

מה זה E2E Testing?

Unit Test בודק פונקציה אחת בבידוד. מהיר — אבל לא רואה את התמונה הגדולה. משתמש ב-mock במקום דפדפן.
E2E Test מפעיל דפדפן אמיתי, מנווט כמו משתמש. אין mock. אם האתר משתנה — הטסט מתריע.

באגים

3 באגים — מה ראינו, מה חשבנו, למה ככה

05 — כפתור hidden
מה ראינו: query_selector מצא את הכפתור, אבל click() זרק TimeoutError.
מה חשבנו: הכפתור קיים ב-DOM — למה הוא לא לחיץ? בדקנו ב-DevTools וגילינו class="hidden".
הפתרון: לחיצה קודם על כפתור ה-dropdown שחושף אותו — כמו שמשתמש אמיתי היה עושה.
06 — Session פג
מה ראינו: שגיאת TimeoutError על כפתור שבטח קיים — בלי הסבר.
מה חשבנו: אולי הכפתור השתנה? בדקנו — ואז שמנו לב שה-URL הוא /account/login. הסשן פג.
הפתרון: בדיקת URL בתחילת כל פעולה — שגיאה ברורה במקום TimeoutError מסתורי.
09 — קריאה כפולה
מה ראינו: HTTP 429 מהיר מדי — כאילו שולחים יותר בקשות ממה שצריך.
מה חשבנו: עברנו על הקוד וראינו ש-_assert_session() נקראת פעמיים ברצף — פעם ב-count ופעם ב-add.
הפתרון: הסרנו את הקריאה מ-add_books — הבדיקה ב-BookPage מספיקה.
כל שלושת הבאגים נמצאו רק בריצה אמיתית — לא בקוד review ולא בסטאטיק אנליזה.
מנגנונים

שני מנגנונים שחסכו את הפרויקט

Exponential Backoff — נגד HTTP 429
האתר חוסם בקשות מהירות מדי.
בכל כישלון — ממתינים כפול מהפעם הקודמת.
5s → 10s → 20s → 40s + ±2s אקראי
Jitter — הרעש האקראי מונע מריצות מקבילות לפגוע בשרת בו-זמנית.
בנוסף: תנועת עכבר אנושית · delays אקראיים · הסרת webdriver flag
Delta Assertion — עמיד לריצות חוזרות
במקום לבדוק ערך מוחלט (assert count == 5)
בודקים את השינוי: כמה נוסף.
after − before == added ✓
ריצה שנייה? הרשימה כבר מכילה ספרים — הטסט עדיין עובר.
למה לא לנקות? מחיקה = HTTP requests נוספים = 429 מהר יותר.

מסקנות

מה לוקחים מהפרויקט

כישלון שקט None → exception, לא המשך selector שמחזיר None בשקט גרוע יותר מקריסה. הטסט "יעבור" בלי לבדוק כלום.
Selectors טקסט יציב יותר מ-class :has-text() עמיד לשינויי CSS. Class names משתנים ברדיזיין — טקסט פחות. DevTools לפני קוד.
POM הפרדת אחריות — השקעה שחוזרת כשהאתר שינה כפתורים — תיקנו 3 שורות ב-Page Object. הטסטים לא ידעו שמשהו השתנה.
Real-world אל תניח — תבדוק "בטח אין ספרים מ-1800" — יש, מ-1484. הריצה הראשונה תשבור הנחות — בדיוק בשביל זה עושים E2E.
